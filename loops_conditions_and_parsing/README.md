# Loops, Conditions and Parsing

Bash scripts covering loops, conditional statements, file test operators and log parsing.

- 1-for_best_school: displays "Best School" 10 times using a for loop.
- 2-while_best_school: displays "Best School" 10 times using a while loop.
- 3-until_best_school: displays "Best School" 10 times using an until loop.
- 4-if_9_say_hi: displays "Best School" 10 times and "Hi" after the 9th iteration.
- 5-4_bad_luck_8_is_your_chance: loops from 1 to 10 with luck messages on 4 and 8.
- 6-superstitious_numbers: displays 1 to 20 with superstition messages using case.
- 7-clock: displays the time for 12 hours and 59 minutes.
- 8-for_ls: lists the current directory showing only the part after the first dash.
- 9-to_file_or_not_to_file: gives information about the school file.
- 10-fizzbuzz: displays 1 to 100 with Fizz, Buzz and FizzBuzz.
- 11-read_and_cut: displays username, user id and home directory from /etc/passwd.
- 12-tell_the_story_of_passwd: tells a story based on /etc/passwd using IFS.
- 13-lets_parse_apache_logs: displays visitor IP and HTTP status code from the Apache log.
- 14-dig_the-data: groups visitors by IP and HTTP code, ordered by occurrences.
